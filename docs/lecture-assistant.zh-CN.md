# 课堂助手（本 fork 新增功能）

在原版"实时字幕 + 翻译"的基础上，本 fork 增加了：

- **自动分节总结**：每讲完一节，用大模型（例如 DeepSeek）生成几句中文小结，按时间线显示在 **Timeline** 页。
- **按课件分节**：上传课件（PPT 或 PDF）后，按老师讲到的页码分节；没有课件时按话题变化分节；自动识别失败时才按固定时间分节。
- **耳机播报**：用 Windows 自带的语音把小结（也可以连同译文）读出来，声音走系统默认输出设备，连上蓝牙耳机即可。
- **导出笔记**：Timeline 页右上角可导出当天的 Markdown 笔记，包含时间线、每节小结、原文和译文。

## 第一次使用

1. **准备 Windows**（Windows 11 22H2 及以上）
   - 设置 → 时间和语言 → 语言和区域：添加课程语言（例如英语），并确保"语音识别"组件已安装，实时辅助字幕才能识别这门语言。
   - 想听中文播报，需要安装中文语言包的"文本到语音"组件（自带"Microsoft Huihui"等中文语音）。
   - 扫描版课件要用 OCR 时，课程语言的语言包里要包含"光学字符识别"（一般随语言包自动安装）。

2. **打开左侧导航的"课堂设置"页**（第二个图标），所有设置都在这一页：
   - **⓪ 输入源**：网课 / 视频选"电脑播放的声音"；线下课选"麦克风"，再选用哪个麦克风。软件会自动替你打开或关闭实时辅助字幕的"包含麦克风音频"；如果自动设置失败，会弹出实时辅助字幕的设置菜单，请手动勾选。不要选蓝牙耳机上的麦克风，否则耳机会切换到通话模式，音质变差。
   - **① 模型与 API**：选服务商（DeepSeek / 通义千问 / 其他 OpenAI 兼容接口），地址会自动填好；粘贴 API Key，选或输入模型，点"测试连接"确认可用。"翻译也用这个模型"打开时，翻译和小节总结都用它；关掉则翻译改用免费的 Google 翻译。
   - **② 课件**：上传本节课的 PDF（也支持 .pptx），可选。扫描版或图片页会自动用 Windows 自带的 OCR 识别；可以选择 OCR 语言，文字乱码时打开"所有页面都用 OCR"。
   - **③ 分节总结**：分节方式、每节最长时长、按时间分节的间隔。
   - **④ 耳机播报**：输出设备、读出内容（关闭 / 只读小节总结 / 总结 + 译文）、语音、语速、音量；"试听"可以检查耳机里有没有声音。
     - 实时辅助字幕会"听"Windows 默认输出设备里的所有声音。如果播报也从默认设备播出，它会把播报内容也识别进字幕，所以这时软件会在播报期间暂停接收字幕。
     - 线下课最好的设置：在这里把输出设备直接选成蓝牙耳机，同时把 Windows 默认输出设为电脑扬声器。这样播报只进耳机，字幕不会中断。

## 上课时

- 课前在"课堂设置"或 Timeline 页上传课件（可选）。旧版 .ppt 请先另存为 PDF。
- **点右上角的"开始"**：软件会确认实时辅助字幕在运行、按"输入源"打开或关闭麦克风，然后才开始读字幕、翻译和分节。下课点"停止"。如果 15 秒都没识别到文字，字幕页会提示可能的原因。
- **Ctrl+Alt+S**：立即结束本节并生成小结（老师换话题而工具没跟上时用）。
- **Ctrl+Alt+M**：打开 / 关闭耳机播报。
- 标题栏上有"结束本节"的旗子按钮和"耳机播报"开关，作用同上两个快捷键。
- 字幕页右侧一栏实时显示今天的小节总结；拖动两栏中间的分隔条可以调整宽度。

## 已知限制

- 识别质量取决于 Windows 实时辅助字幕和拾音条件。线下课尽量坐前排，或者用外接麦克风。
- "总结 + 译文"模式下，播报跟不上时会自动跳过较旧的译文，只保留最新的两句。
- 自动分节每隔约 40 秒请求一次大模型。载入课件后请求里会带上附近几页的文字，因此会多用一些 token，按 DeepSeek 的价格估算，一节课仍在几毛到一两块钱的量级。
- 在 History 页"删除全部历史"会把 Timeline 上的小节一起删掉，因为小节引用的就是这些历史记录。
- 本 fork 关闭了"有新版本"提示，以免误装原版、丢掉这些功能。
